# Reference: common learner misconceptions about AI (ages 13-17)

Used by: accuracy-safety-reviewer, curriculum-instructional-designer, novice-learner-panel, analogy-specialist, educator-enablement.

A starting list compiled by the build team from common patterns in AI education; to be validated against the creator's research and pilot data. A lesson must not *create or reinforce* these, and a strong lesson surfaces one and lets the learner test it.

1. **AI understands meaning.** It finds patterns in data; it does not know what the patterns are about.
2. **AI is always right / objective.** It is as good, and as biased, as its data and the choices people made.
3. **Someone wrote all the rules.** Many systems learn their settings from examples (training); others are hand-written. Lessons should say which.
4. **AI learns continuously from me.** Most deployed systems do not update from each user in real time; say what a given system does.
5. **More data always fixes it.** More of the same biased or mislabelled data repeats the problem.
6. **AI is a single super-brain / a robot.** Different systems do narrow tasks.
7. **If it sounds confident, it is correct.** Confidence scores and fluent text are not truth.
8. **AI has intentions (wants to help, decided to protect).** It optimises what it was built to; it does not want.
9. **A high/low threshold can make a filter perfect.** Every threshold trades one kind of mistake for another.
10. **Errors mean the system is broken.** Every pattern-based system makes some mistakes; the question is which and how many.
