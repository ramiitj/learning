# Component catalogue (v1 universal primitives)

Source: `docs/05-interaction-components.md`. Lessons may use only these components. A new component is an architecture change that needs the creator's approval; propose it in notes instead.

| Component | Learner action | Purpose | Classroom variant |
|---|---|---|---|
| `reveal` | Uncover the next idea | Connective pacing between acts (not an act by itself) | Teacher reveals |
| `predict` | Commit to a guess, optionally with confidence | Surface misconceptions; make the reveal matter | Class vote |
| `knob` | Change parameters with sliders and watch an output change | Cause-and-effect model; always paired with a goal | Teacher moves the knob; class predicts first |
| `sort` | Drag or tap items into groups | Be the classifier before the machine is | Class votes item by item |
| `assemble` | Put steps or parts in order | Structure and order | Teacher assembles from class suggestions |
| `your-data` | Type or label their own input | Ownership | Class contributes items |
| `by-hand-then-automate` | Do one step by hand, then run it many times | Demystify what the machine does | Teacher steps; class checks |
| `break-it` | Try to make the system fail | Limits, bias, failure modes | Class suggests attempts |
| `compare` | Run two versions side by side | Isolate one variable | Split screen |
| `explain-back` | Pick or write an explanation and its break point | Consolidation and transfer | Pair discussion |
| `analogy` | Explore an analogy that fades into the formal idea | Make the abstract graspable | Teacher-led |
| `check` | Short understanding check with hints and a detour offer | Confirm the ground is solid | Class vote |
| `takeaway` | Keep what they made | Closure and a reason to finish | Class result card |

Supporting elements: glossary terms (tap for a definition), detours (prerequisite side path that returns), depth dial (deeper layers), hint ladder, recall warm-up.

## Refused patterns (Article 14)

Walls of text; "Next" buttons as the main interaction; autoplaying video; quizzes that feel like punishment; guilt-based streaks; generic stock imagery; decorative animation; confetti on routine actions; progress bars as the main motivator; anything resembling a traditional LMS.
